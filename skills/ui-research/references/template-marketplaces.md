# Template marketplaces and inspiration galleries

Every URL below was opened on 2026-10-25 and the description was taken from the page. Counts are what the site said that day and will drift; prices and licences change, so read the listing's licence before recommending a purchase. Some sites block automated fetches; that is not the same as being down.

Contents: 1. How to use this file · 2. Sources by tier · 3. Which source for which niche · 4. Recording a template · 5. Licence cautions

## 1. How to use this file

1. Classify the niche (section 3).
2. Survey at least two sources from the matching tiers; study three to five strong examples.
3. Record each one with the template in section 4.
4. Present options to the user (format in `../SKILL.md`). The user chooses.

## 3. Which source for which niche

| Niche | Start with | Also look at |
|---|---|---|
| SaaS or startup marketing | Tailwind Plus, Cruip, Framer | SaaS Landing Page, Lapa Ninja, Land-book |
| Developer tool | Tailwind Plus, shadcn/ui Blocks, Vercel Templates | Godly, Land-book |
| App screens and flows | the project's design system | Mobbin |
| Dashboard or admin | shadcn/ui Blocks, AdminLTE, CoreUI | Mobbin (tables, filters, empty states) |
| E-commerce storefront | Shopify Theme Store, ThemeForest | Land-book (product pages) |
| Agency or portfolio | Framer, Webflow, Qode Interactive | Awwwards, Godly, One Page Love |
| Local business (fitness, restaurant, salon, clinic, legal) | ThemeForest, Qode Interactive, TemplateMonster | Webflow by category |
| Blog or publication | ThemeForest (WordPress) | Land-book (blog pages) |
| Non-profit or events | ThemeForest, Webflow | One Page Love |
| Free or open-source project site | HTML5 UP, Start Bootstrap | One Page Love |

## 4. Recording a template

```
Template: <name>             Source: <marketplace>      Link: <demo or listing URL>
Price / licence: <free, MIT, CC BY, paid single-use ...>
Section order: 1. <hero type> 2. <...> 3. <...>
Navigation: <fixed top / sidebar / minimal>   Footer: <multi-column / minimal>
Palette approach: <dark/light, accent use>   Type: <heading and body families, weights>
Layout: <full width / boxed / asymmetric>, grid: <columns>
What makes it work: <one or two lines>
```

After three to five records, write the shared pattern: the sections every strong example in the niche includes, the colour and type conventions, and the distinctive elements of the niche.

## 5. Licence cautions

- Inspiration galleries show other people's live sites. Learn structure from them; never copy their assets, copy text or code.
- Paid marketplace templates are licensed per purchase and per use; the user must buy and own the licence before its code or assets go into the project.
- Free templates still have licences. HTML5 UP is CC BY 3.0 and needs a credit; Start Bootstrap is MIT. Keep required credits.
- Fonts and images bundled with a template may carry their own licences.
